# LaTeX Templates Collection

A collection of curated LaTeX templates to ace Engineering Physics assignments :)

## How to use

1. Clone the repository.
2. Navigate to the desired folder.
3. Open .tex files in your desired editor (Overleaf, VS Code, TeXworks, VIM,...).

*(**pro tip**: get used to using an offline editor. The (free) Overleaf compiling time keeps getting shorter, and it might not be enough for some lab reports or your thesis...)*
